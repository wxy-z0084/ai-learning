AI 能力成长学习计划（细分版）

五大阶段能力画像 · 学习内容细分及预估时长 · 点击任意学习内容即可进入对应学习页面

📌 学习用法说明（务必先看）

1

二八法则

每个知识点：读本页(10min) → 读推荐官方文档核心(30min) → 动手跑通示例(1h+) → 写一条笔记。动手应占 60% 以上时间，只"看目录"等于没学。

2

设里程碑

别逐个刷 113 个知识点。每个阶段结束做一个小项目（见各阶段"🎯 里程碑项目"），把零散知识串成能拿得出手的作品。

3

找反馈

把代码/笔记发到 GitHub、加入 AI 学习社群，让他人帮你发现盲区——这是静态计划替代不了的"纠偏回路"。

⚠ 数学原理是盲区：本计划偏工程应用层，未含线性代数、概率、微积分与 Transformer 内部机制。学到阶段五容易"知其然不知其所以然"。建议并行补充：吴恩达《Machine Learning》基础课、李宏毅《机器学习》、《动手学深度学习》（D2L）第 1–5 章。
一

指挥AI写软件

能力画像

掌握 Coze 平台使用、提示词工程与多模态应用搭建以及 Vibe Coding 的能力，具备 AI 智能体快速开发能力。

学习内容细分：

1. Coze 平台使用 约 3 天

  • 账号注册与工作区管理0.5 天
  • Bot 创建与人设配置0.5 天
  • 插件调用与工作流编排1 天
  • 知识库（文档/表格）配置0.5 天
  • 变量、记忆与数据库功能0.5 天
  • 发布到 Web / 微信 / 飞书等渠道0.5 天

2. 提示词工程 约 3 天

  • 提示词结构设计（角色、任务、约束、格式）1 天
  • Few-shot 示例提示0.5 天
  • 思维链（CoT）与逐步推理0.5 天
  • 提示词模板化与版本管理0.5 天
  • 提示词评估与迭代优化0.5 天

3. 多模态应用搭建 约 2 天

  • 文本 + 图像输入输出处理0.5 天
  • 语音识别与合成应用0.5 天
  • 多模态大模型（图文理解）调用0.5 天
  • 多模态插件组合搭建场景应用0.5 天

4. Vibe Coding 约 2 天

  • AI 结对编程工具使用（Cursor、Copilot 等）0.5 天
  • 上下文与需求描述技巧0.5 天
  • AI 生成代码的审查与调整0.5 天
  • 自然语言驱动的快速迭代开发0.5 天

5. AI 智能体快速开发 约 2.5 天

  • 零代码/低代码智能体搭建流程0.5 天
  • 智能体场景选题与需求拆解0.5 天
  • 实战：客服、写作、办公助手等应用1 天
  • 智能体发布与效果验证0.5 天
建议周期：第 1 - 2 周
🎯 里程碑项目：做一个能用的 Coze 客服 / 写作助手

在 Coze 搭一个带知识库、能调插件、会记住对话上下文的 Bot，发布到网页或飞书；用阶段二学到的提示词技巧把回答质量调到位，对外可用即过关。

二

智能体开发

能力画像

掌握 Python 全栈、FastAPI、RAG 与 LangChain，具备企业级 AI 智能体开发与部署能力。

学习内容细分：

1. Python 全栈 约 4 天

  • Python 语法进阶与常用标准库1 天
  • 异步编程（asyncio）与并发处理1 天
  • 包管理与工程化项目结构0.5 天
  • 前端基础（HTML/CSS/JS、Streamlit）1 天
  • 数据库操作（SQL / ORM）0.5 天

2. FastAPI 约 4 天

  • 路由、请求与响应模型（Pydantic）1 天
  • 依赖注入与中间件0.5 天
  • 接口鉴权（JWT / OAuth2）0.5 天
  • 流式响应（SSE / WebSocket）1 天
  • 接口测试（Swagger）与部署（Uvicorn/Docker）1 天

3. RAG（检索增强生成） 约 4.5 天

  • 文档加载与切分策略1 天
  • Embedding 向量化原理0.5 天
  • 向量数据库使用（Milvus / Chroma / FAISS）1 天
  • 检索策略（混合检索、重排序）1.5 天
  • RAG 效果评估与优化0.5 天

4. LangChain 约 5 天

  • 核心组件：Model / Prompt / Chain1 天
  • Agent 与 Tool（工具调用）1 天
  • 对话记忆（Memory）管理0.5 天
  • LCEL 声明式链路编排1 天
  • LangGraph 多步智能体工作流1.5 天

5. 企业级开发与部署 约 4 天

  • 智能体工程化目录与配置管理0.5 天
  • 日志、监控与异常处理0.5 天
  • Docker 容器化与发布流程1 天
  • API 限流、成本控制与安全0.5 天
  • 实战：企业知识库问答智能体1.5 天
建议周期：第 3 - 6 周
🎯 里程碑项目：企业知识库问答智能体（带 RAG + 流式界面）

用 Python + FastAPI + LangChain + Milvus/Chroma 搭一个能上传文档、向量检索、流式回答并显示引用来源的知识库问答系统，Docker 部署可访问。

三

软件工程化

能力画像

掌握 Java/SpringBoot 与企业级单体项目开发，具备业务系统 AI 集成与低代码开发能力。

学习内容细分：

1. Java / SpringBoot 约 5 天

  • Java 语法进阶与集合、多线程1 天
  • Spring IoC 与 AOP 原理1 天
  • SpringMVC 与 RESTful 开发1 天
  • MyBatis / JPA 数据访问1 天
  • SpringBoot 自动配置与 Starter1 天

2. 企业级单体项目开发 约 5 天

  • 分层架构设计（Controller-Service-DAO）1 天
  • 统一响应、异常处理与参数校验1 天
  • 权限认证（Spring Security / Sa-Token）1 天
  • 缓存（Redis）、任务调度（Quartz）1 天
  • 单元测试与接口文档（Knife4j）1 天

3. 业务系统 AI 集成 约 5 天

  • 调用大模型 API（OpenAI / 国产大模型）1 天
  • 流式输出与对话管理1 天
  • Function Calling 工具调用集成1 天
  • 业务数据注入提示词（提示词模板管理）0.5 天
  • AI 能力封装为业务模块（审核、摘要、生成）1.5 天

4. 低代码开发 约 3 天

  • 低代码平台核心概念与选型0.5 天
  • 表单、流程、页面可视化配置1 天
  • 低代码与自定义代码扩展结合1 天
  • 低代码应用与 AI 能力集成0.5 天
建议周期：第 7 - 10 周
🎯 里程碑项目：给一个单体业务系统接入 AI 能力

用 Java/SpringBoot 写一个带登录鉴权、Redis 缓存的博客/工单系统，并把"AI 摘要、AI 审核、AI 生成"封装成业务模块，低代码平台也复刻一遍核心表单流程。

四

业务解决方案

能力画像

掌握微服务架构、分布式方案、多智能体开发，具备企业级项目智能化升级与高并发系统落地能力。

学习内容细分：

1. 微服务架构 约 4.5 天

  • 服务拆分原则与设计0.5 天
  • 注册中心与配置中心（Nacos）1 天
  • API 网关（Gateway）与负载均衡1 天
  • 服务调用（OpenFeign）与熔断降级（Sentinel）1.5 天
  • 链路追踪与分布式日志0.5 天

2. 分布式方案 约 4.5 天

  • 分布式事务（Seata、最终一致性）1 天
  • 消息队列（RabbitMQ / Kafka）1 天
  • 分布式缓存与 Redis 集群1 天
  • 分库分表（ShardingSphere）1 天
  • 高可用与容灾设计0.5 天

3. 多智能体开发 约 4 天

  • 多智能体角色分工与任务规划0.5 天
  • 智能体间通信与协作机制1 天
  • 编排框架（LangGraph / CrewAI / AutoGen）1 天
  • 共享记忆与状态管理0.5 天
  • 多智能体冲突处理与结果汇总1 天

4. 企业级项目智能化升级 约 3 天

  • 存量系统 AI 升级需求分析与评估1 天
  • AI 能力嵌入现有业务流程的方案设计1 天
  • 新旧系统数据与接口打通0.5 天
  • 灰度发布与回滚机制0.5 天

5. 高并发系统落地 约 4 天

  • 性能压测（JMeter）与瓶颈定位1 天
  • JVM 调优与 SQL 优化1 天
  • 限流、熔断与降级策略0.5 天
  • 容量规划与弹性伸缩0.5 天
  • 实战：高并发业务系统 AI 智能化升级1 天
建议周期：第 11 - 14 周
🎯 里程碑项目：高并发 + 多智能体协作的智能化升级实战

把阶段三的单体系统拆成微服务，接 Nacos/Gateway/Sentinel，用多智能体（LangGraph/CrewAI）做任务编排，再压测 + JVM/SQL 调优，给出灰度升级方案。

五

传统项目智能化升级

能力画像

具备项目集成 AI 能力实现智能化升级，掌握 LoRA 微调、模型评估与部署，具备大模型优化与生产级上线的全流程能力。

学习内容细分：

1. 项目集成 AI 能力 约 2.5 天

  • 传统项目 AI 升级可行性评估0.5 天
  • 智能化升级方案设计（提示词 / RAG / 微调选型）1 天
  • AI 接口与业务数据打通0.5 天
  • 升级效果验证与业务价值评估0.5 天

2. LoRA 微调 约 5 天

  • 微调场景判断（何时微调 vs RAG）0.5 天
  • 训练数据收集、清洗与格式构造1.5 天
  • LoRA / QLoRA 原理与参数配置1 天
  • 训练框架使用（LLaMA-Factory 等）1 天
  • 微调效果验证与迭代1 天

3. 模型评估与部署 约 4 天

  • 评估指标（准确率、鲁棒性、业务指标）1 天
  • 自动化评估集与评测流程1 天
  • 推理服务搭建（vLLM / Ollama）1 天
  • 模型版本管理与灰度切换1 天

4. 大模型优化 约 3.5 天

  • 模型量化（GPTQ / AWQ）1 天
  • 剪枝与蒸馏基础0.5 天
  • 推理加速与显存优化1 天
  • 提示缓存与调用成本优化1 天

5. 生产级上线全流程 约 4 天

  • CI/CD 与自动化发布1 天
  • 线上监控告警与效果回归1 天
  • A/B 测试与迭代闭环0.5 天
  • 安全合规（内容安全、数据隐私）0.5 天
  • 实战：传统项目大模型智能化升级上线1 天
建议周期：第 15 - 18 周
🎯 里程碑项目：传统项目大模型智能化升级上线（全流程）

选一个真实/模拟旧系统，完成可行性评估 → RAG 或 LoRA 微调选型 → 用 LLaMA-Factory 微调并量化部署（vLLM/Ollama）→ 接入 CI/CD、监控告警、A/B 测试，最终上线。
