数据库操作（SQL / ORM）

预计 0.5 天模块一 · Python 全栈

一、学习目标

  • 能够手写增删改查四类 SQL，并用 JOIN、GROUP BY 完成两张表以上的关联统计。
  • 能够为业务设计带主键、外键、唯一约束与索引的表结构，并说明为什么必须用参数化查询。
  • 能够用 SQLAlchemy 2.0 完成模型定义、会话管理与 CRUD，读懂 ORM 生成的查询语义。
  • 能够用 Alembic 管理表结构变更，理解「迁移脚本进版本库」的团队协作要求。

二、核心知识点

知识点 1：SQL 基础与安全

关系数据库用表组织数据，每行是一条记录、每列是一个字段。核心四句：INSERT INTO t (cols) VALUES (...)、SELECT 列 FROM t [JOIN u ON ...] [WHERE ...] [GROUP BY ...] [ORDER BY ...] [LIMIT n]、UPDATE t SET 列=值 WHERE 条件、DELETE FROM t WHERE 条件。写错 WHERE 是生产事故之最，习惯先用 SELECT 把条件跑一遍确认影响行数再执行更新。多表用 INNER JOIN 取交集、LEFT JOIN 保左表（右表无匹配补 NULL），统计配合 COUNT/SUM 与 HAVING 过滤分组结果。

安全红线：永远不要用字符串拼接 SQL。拼接会让用户输入变成 SQL 语法（SQL 注入），且无法命中缓存计划。正确做法是参数化查询——占位符 + 单独的参数列表，由驱动完成转义。另一类风险是事务：多步写入要么全部成功要么全部回滚，用 BEGIN/COMMIT/ROLLBACK 或 ORM 的 session 事务边界控制。

知识点 2：表设计与索引

设计要点：主键唯一标识一行（推荐自增 id 或 UUID）；外键表达表间关系并保证引用完整性；UNIQUE 约束防重复（如用户名、邮箱）；NOT NULL、默认值、CHECK 约束把合法性下沉到数据库。字段类型选准：短文本 varchar、长文本 text、金额用 DECIMAL 而不是 float、时间用 DATETIME/TIMESTAMP 并统一存 UTC。

索引是加速查询的数据结构，代价是写入变慢、占空间。建索引的判断标准：该列经常出现在 WHERE / JOIN / ORDER BY 中且区分度高；最左前缀原则意味着联合索引 (user_id, created_at) 能服务 user_id 单独查询，反过来不行。切忌「每列都建索引」，也别对频繁更新的小表建索引。

知识点 3：用 SQLAlchemy 2.0 做 ORM

ORM（对象关系映射）把 Python 类映射为表、实例映射为行，让你用 Python 语法操作数据库。SQLAlchemy 2.0 的写法：DeclarativeBase 定义基类，类属性用 Mapped[...] + mapped_column(...) 声明类型与约束，查询统一走 select() 语句对象，通过 Session 执行。会话是「工作单元」：同一事务内的改动会被一起 flush 与 commit。三大坑：① 忘记 commit，改动不会落库；② 在循环里逐条 insert，应改用 session.add_all 或 bulk 方式；③ 修改了对象却不 commit 就查询，读到的是会话缓存而非库中真实数据。ORM 生成的 SQL 可用 print(stmt) 或开启 echo=True 查看，复杂统计查询直接写原生 SQL 也完全合理——ORM 不是信仰，是工具。

知识点 4：迁移与异步访问

表结构变更用 Alembic 管理：alembic init 生成配置，alembic revision --autogenerate 对比模型自动生成迁移脚本，alembic upgrade head 应用。迁移脚本必须提交到 git，部署时先升级数据库再发应用。开发期可随时重建的原型库（如 SQLite）可跳过 Alembic，但只要有多人协作或线上数据就必须用。异步场景（配合 FastAPI/asyncio）要用 async_sessionmaker + create_async_engine，查询改为 await session.execute(...)，否则同步驱动会阻塞事件循环。

三、示例演示

示例一：安全的原生 SQL 用法（sqlite3 参数化 + 事务），可直接运行：

import sqlite3

conn = sqlite3.connect("app.db", check_same_thread=False)
cur = conn.cursor()
cur.execute("""
    CREATE TABLE IF NOT EXISTS message (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        user_id INTEGER NOT NULL,
        content TEXT NOT NULL,
        created_at TEXT DEFAULT CURRENT_TIMESTAMP
    )
""")

# 参数化：问号占位符，用户输入放在 args 里，天然防注入
def save_message(user_id: int, content: str) -> int:
    cur.execute(
        "INSERT INTO message (user_id, content) VALUES (?, ?)",
        (user_id, content),
    )
    conn.commit()                     # 不 commit 不会落库
    return cur.lastrowid

def count_by_user(user_id: int) -> int:
    cur.execute(
        "SELECT COUNT(*) FROM message WHERE user_id = ?",
        (user_id,),
    )
    return cur.fetchone()[0]

save_message(1, "你好")
print("该用户消息数：", count_by_user(1))
conn.close()

示例二：SQLAlchemy 2.0 风格的模型、会话与关联查询：

from datetime import datetime
from sqlalchemy import ForeignKey, String, select, func
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, relationship, Session,
)
from sqlalchemy import create_engine

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50), unique=True)
    messages: Mapped[list["Message"]] = relationship(
        back_populates="user", cascade="all, delete-orphan"
    )

class Message(Base):
    __tablename__ = "messages"
    id: Mapped[int] = mapped_column(primary_key=True)
    content: Mapped[str] = mapped_column(String(500))
    created_at: Mapped[datetime] = mapped_column(default=datetime.utcnow)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id"))
    user: Mapped[User] = relationship(back_populates="messages")

engine = create_engine("sqlite:///app.db", echo=True)
Base.metadata.create_all(engine)

with Session(engine) as session:
    alice = User(name="alice",
                 messages=[Message(content="第一条"), Message(content="第二条")])
    session.add(alice)                # 级联插入两条消息
    session.commit()

    # 等价 SQL：SELECT users.name, COUNT(messages.id) ... GROUP BY ...
    stmt = (
        select(User.name, func.count(Message.id))
        .join(Message, Message.user_id == User.id)
        .group_by(User.name)
        .order_by(func.count(Message.id).desc())
    )
    for name, cnt in session.execute(stmt):
        print(name, cnt)
💡 提示：看不懂 ORM 在干什么时，打开 echo=True 看它打印的真实 SQL——这是最快的 ORM 学习法，也能帮你发现 N+1 查询（循环里逐条查关联数据，应改用 joinedload 或一次 JOIN）。
