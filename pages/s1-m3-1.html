阶段一 · 指挥AI写软件

文本 + 图像输入输出处理

预计 0.5 天模块三 · 多模态应用搭建

一、学习目标

  • 能够说清多模态消息中文本与图像的表示方式（URL、Base64 两种编码）及各自的适用场景。
  • 能够在 Coze 等平台的 Bot / 工作流中完成图片上传、图片识别与图片生成三类典型配置。
  • 能够设计同时包含文字与图片的回复输出结构，让应用稳定返回图文混排内容。
  • 能够排查图片输入失败、生成结果不合规等常见问题。

二、核心知识点

知识点 1：图像的两种携带方式——URL 与 Base64

模型无法直接"看到"文件，图像必须以数据形式随请求一起发送，常见有两种方式：图片 URL 与 Base64 编码。URL 方式只需要一个公网可访问的链接，请求体轻、便于存储和缓存，但要求链接长期有效且模型服务端能下载到；Base64 把二进制图片转成一段文本直接塞进请求，不依赖外网，适合临时文件和内网场景，缺点是体积膨胀约 1/3，会占用更多上下文与带宽。

实际选择经验：用户在聊天框里上传的图片，平台通常会先转存拿到一个 URL 再传给模型；而服务端动态渲染的图表（如 matplotlib 生成的柱状图）没有稳定地址，一般直接转 Base64 传入。

知识点 2：在 Coze 中处理图片输入

Coze 的 Bot 在「人设与回复逻辑」之外，还需要在技能 / 插件里开启相应能力。让用户上传图片时，要在 Bot 设置中允许用户输入包含图片（消息里会出现 img 类型的多模态内容），并配合图片理解类插件或具备视觉能力的大模型（如豆包视觉理解、GPT-4o、Claude 3.5 Sonnet）来解析图片内容。

操作要点有三：一是确认所选模型支持视觉输入，纯文本模型收到图片会直接报错或忽略；二是限制图片数量与尺寸（常见限制：单张 10MB 以内、JPG/PNG/WebP 格式），超限会导致上传失败；三是在提示词里明确"先描述图片、再回答问题"，避免模型跳过看图直接编造。

知识点 3：图片生成与图文混排输出

图片输出一般通过图像生成插件（如 Coze 内置的"图片生成"、即梦、DALL·E 等）完成，插件返回的是一张图片 URL，你需要在回复中把它输出为图片卡片或 Markdown 图片语法 ![描述](url)。常见坑有两个：生成的 URL 有有效期，长期展示要转存到自己的对象存储；提示词里若只写"画一只猫"，结果风格不可控，应补全主体、风格、构图、色调、比例等要素。

💡 输出结构化图文时，尽量让插件把「图片地址」和「图片说明」分别作为变量返回，再由回复节点拼接，比让模型自由发挥更稳定。

三、示例演示

下面是一段可直接粘贴到 Coze Bot 提示词里的图文处理指令，规定了收到图片、生成图片时的行为：

你是一个图文助理，按以下规则工作：

【收到图片时】
1. 先用一句话概括图片主题；
2. 再列出图中可识别的关键要素（人物/物体/文字/场景）；
3. 若用户提出与图有关的问题，基于图片内容回答，无法确认的地方明确说"图中看不出来"，禁止臆测。

【需要生成图片时】
1. 把用户需求扩写为完整提示词：主体 + 风格 + 构图 + 色调 + 比例；
2. 调用图片生成插件，比例默认 3:4；
3. 输出格式：先一行图片说明，再输出图片。

【禁止】编造不存在的图片链接；输出 Base64 文本。

若想在本地验证 Base64 图片输入，可用下面的 Python 片段生成请求体中 image_url 字段的内容：

import base64, mimetypes

def to_data_uri(path: str) -> str:
    mime = mimetypes.guess_type(path)[0] or "image/png"
    with open(path, "rb") as f:
        b64 = base64.b64encode(f.read()).decode()
    return f"data:{mime};base64,{b64}"

print(to_data_uri("demo.png")[:80])  # data:image/png;base64,iVBORw0KGgo...
💡 提示：Base64 字符串不要写进提示词里当普通文本，它必须放在请求的结构化字段（如 messages 中的 image_url）中，模型才会真正把它当作图像解析。

四、实践任务

  1. 任务 1：在 Coze 新建一个 Bot，开启图片理解能力，上传一张含文字的截图，让它准确读出图中文字并总结截图内容。
  2. 任务 2：为该 Bot 添加图片生成插件，用"主体+风格+构图+色调+比例"的结构化提示词生成一张指定风格的图片，记录生成结果与你的提示词差异。
  3. 任务 3：在工作流中串联"文本输入 → 图片生成 → 图文回复"三个节点，跑通一次完整流程并截图留档。
  4. 任务 4（进阶，可选）：用上面的 Python 函数把本地图片转成 Base64，对比 URL 方式与 Base64 方式在体积和成功率上的差别。
