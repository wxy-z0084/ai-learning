阶段二 · 智能体开发

前端基础（HTML/CSS/JS、Streamlit）

预计 1 天模块一 · Python 全栈

一、学习目标

  • 能够用语义化的 HTML 标签搭出结构清晰的页面（标题层级、表单、列表），不靠一堆无语义的 div。
  • 能够用 CSS 选择器、盒模型与 flex 布局完成常见排版，并理解为什么样式要「类选择器优先、少用 !important」。
  • 能够用原生 JavaScript 完成 DOM 操作、事件绑定与 fetch 调接口，看懂前后端数据交互的最小闭环。
  • 能够用 Streamlit 在纯 Python 环境下快速做出带交互的数据/智能体演示页面，理解其「每次交互都重跑脚本」的运行模型。

二、核心知识点

知识点 1：HTML——用语义标签描述内容结构

HTML 是描述结构的标记语言，不是编程语言。骨架固定为 doctype、head（字符集、viewport、title、引入 css/js）、body。常用语义标签：h1~h6 表示标题层级（一页只应有一个 h1）、p / ul / ol / a / img 表示内容、header / nav / main / section / footer 划分区块、form / label / input / button 收集用户输入。给 label 配 for 与输入框 id 关联，能提升可访问性并扩大点击区域。表单提交方式要分清：GET 参数拼在 URL、POST 放请求体。

知识点 2：CSS——选择器、盒模型与 flex 布局

CSS 规则由「选择器 + 声明块」组成，优先级从高到低大致是：行内 style > id > 类 > 标签；相同权重看就近覆盖，!important 只在万不得已时用，否则样式难以维护。每个元素都是一个盒子：content + padding + border + margin，默认 box-sizing: content-box 时 width 不含 padding，实践中普遍写 *, *::before, *::after { box-sizing: border-box; } 让 width 即总宽，避免加边框就溢出。

现代排版主力是 display: flex：容器设 flex-direction（row/column）、justify-content（主轴分布）、align-items（交叉轴对齐），子项用 flex: 1 均分空间；需要多行换行加 flex-wrap。做手机适配常配 @media (max-width: 768px) 断点改布局，配合 max-width: 1200px + margin: auto 居中容器。

知识点 3：JavaScript——DOM、事件与 fetch

DOM 把文档变成可编程的节点树，用 document.querySelector 选中元素、textContent/innerHTML 改内容、classList.add 改样式；事件用 addEventListener('click', handler) 绑定，避免行内 onclick，因为同一事件可绑多个监听且易分离结构与行为。异步请求用 fetch(url)，它返回 Promise：await fetch 拿到 Response 后还要 await resp.json() 才是数据；注意 fetch 默认不为 4xx/5xx 抛错，需手动判断 resp.ok。前端调后端还必须处理 CORS：跨域时后端要允许来源，或开发期用 Vite 代理转发。

知识点 4：Streamlit——纯 Python 的交互式应用

Streamlit 让你用几十行 Python 生成带组件的 Web 页面，适合做智能体 Demo、数据看板。核心心智模型：脚本从头到尾顺序执行——用户每点一次按钮，整个脚本重跑一遍，因此所有输入组件都有返回值（st.text_input 返回当前值），要保存跨次运行的变量必须放进 st.session_state。重跑意味着昂贵操作会被重复执行，用 @st.cache_data（缓存数据）/ @st.cache_resource（缓存模型、连接）避免每次重新加载大模型。st.sidebar 放参数区，st.columns 做分栏，st.form + st.form_submit_button 让多个输入「提交一次才触发重跑」，能显著提升表单类页面体验。

三、示例演示

示例一：一个完整的最小页面，包含语义结构、flex 布局和用 JS 调后端接口：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>智能体问答</title>
  <style>
    *, *::before, *::after { box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; margin: 0; }
    main { max-width: 720px; margin: 0 auto; padding: 24px; }
    .row { display: flex; gap: 8px; }
    .row input { flex: 1; padding: 8px; }
    button { padding: 8px 16px; }
    #answer { margin-top: 16px; padding: 12px; background: #f5f5f5; }
  </style>
</head>
<body>
  <main>
    <h1>智能体问答</h1>
    <form id="ask-form">
      <div class="row">
        <label for="q" class="sr-only">问题</label>
        <input id="q" name="q" placeholder="输入你的问题" required>
        <button type="submit">提问</button>
      </div>
    </form>
    <div id="answer" hidden></div>
  </main>
  <script>
    const form = document.getElementById('ask-form');
    const box = document.getElementById('answer');
    form.addEventListener('submit', async (e) => {
      e.preventDefault();                       // 阻止表单默认整页刷新
      const q = document.getElementById('q').value;
      box.hidden = false;
      box.textContent = '思考中…';
      try {
        const resp = await fetch('/api/ask', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ question: q }),
        });
        if (!resp.ok) throw new Error('HTTP ' + resp.status);
        const data = await resp.json();
        box.textContent = data.answer;
      } catch (err) {
        box.textContent = '请求失败：' + err.message;
      }
    });
  </script>
</body>
</html>

示例二：带会话状态与缓存的 Streamlit 智能体页面，保存为 app.py 后运行 streamlit run app.py：

import time
import streamlit as st

st.set_page_config(page_title="智能体演示", layout="centered")
st.title("🤖 智能体问答演示")

# 缓存昂贵资源：模型只加载一次，不随脚本重跑而重复加载
@st.cache_resource
def load_model():
    time.sleep(1)                # 模拟加载耗时
    return {"name": "demo-model"}

model = load_model()
st.caption(f"当前模型：{model['name']}")

# 用 form 让多个输入提交一次才触发重跑，避免每敲一个字就刷新
with st.form("chat"):
    question = st.text_input("你的问题", max_chars=200)
    temperature = st.slider("温度", 0.0, 1.0, 0.3)
    submitted = st.form_submit_button("发送")

if submitted and question:
    # session_state 跨"重跑"保存对话历史
    history = st.session_state.setdefault("history", [])
    history.append(("user", question))
    answer = f"（模拟回答，温度={temperature}）你问的是：{question}"
    history.append(("assistant", answer))
    for role, text in history:
        st.chat_message(role).write(text)
💡 提示：分不清「结构、样式、行为」时就问自己——这行代码删掉页面还能读懂吗（HTML）？它只影响外观吗（CSS）？它在响应事件吗（JS）？三层分离是最重要也最容易被忽视的前端纪律。

四、实践任务

  1. 任务 1：写一个个人主页 HTML：包含 h1 标题、简介段落、技能 ul 列表和一个「联系我」的表单（姓名输入框 + 提交按钮），用浏览器打开检查标题层级与 label 关联是否正确。
